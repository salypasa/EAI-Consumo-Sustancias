Repositorio educativo de datos sintéticos sobre experiencias adversas en la infancia y consumo de sustancias.

# Experiencias adversas en la infancia y consumo de sustancias

## Descripción del proyecto

Repositorio educativo para practicar la organización,
documentación, publicación y análisis de datos
de investigación utilizando GitHub y Python.

El ejercicio se inspira temáticamente en la investigación
sobre experiencias adversas en la infancia y trastornos
adictivos en la edad adulta, dirigida por
Javier Fernández Montalvo y José Javier López Goñi.

## Objetivo

Explorar, mediante datos sintéticos, la distribución
de experiencias adversas en la infancia y su relación
estadística simulada con el consumo de sustancias.

## Naturaleza de los datos

IMPORTANTE: Todos los datos son ficticios.

No corresponden a participantes reales, no proceden
de la tesis original y no permiten obtener conclusiones
científicas sobre poblaciones reales.

## Contenido

- data/: bases de datos sintéticas.
- docs/: diccionario, metodología y documentación.
- metadata/: metadatos estructurados.
- notebooks/: análisis reproducibles en Python.
- resultados/: tablas y visualizaciones.
