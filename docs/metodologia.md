
# Metodología del ejercicio

## Tipo de proyecto

Demostración educativa con datos sintéticos.

## Objetivo

Practicar la organización, descripción y análisis
exploratorio de datos en GitHub y Google Colab.

## Generación de datos

Los registros fueron construidos artificialmente
para representar distintas combinaciones de
experiencias adversas y consumo de sustancias.

No se utilizaron expedientes clínicos,
entrevistas ni registros de participantes reales.

## Variables

Se incluyeron ocho categorías de adversidad infantil,
una variable de edad, un identificador ficticio,
una puntuación acumulada y una variable binaria
de consumo de sustancias.

## Análisis propuestos

1. Frecuencia de experiencias adversas.
2. Distribución del número acumulado de EAI.
3. Comparación descriptiva del consumo según EAI.
4. Visualización de relaciones entre variables.

## Limitaciones

Los datos no son representativos.
No permiten estimar prevalencias reales.
No permiten establecer causalidad.
No reproducen resultados de la tesis de referencia.

## Consideraciones éticas

No se incluyen datos personales reales.
El material se utiliza únicamente para aprendizaje.
